# 🤖 Personal AI Assistant

A smart personal AI assistant built with Python and the Claude API. It helps users answer questions, perform basic desktop tasks, and interact using voice commands.

## ✨ Features

- 🧠 AI-powered question answering using Claude.
- 🎙️ Voice commands and speech recognition.
- 🖥️ Desktop application control.
- 📝 Automatic text typing in Notepad.
- 🔎 Search for information quickly.
- 💬 Natural conversations with AI.
- ⚡ Fast and simple user interaction.

## 🛠️ Technologies Used

- **Language:** Python
- **AI Model:** Claude API
- **Interface:** Desktop GUI
- **Voice Processing:** Speech recognition and text-to-speech
- **Automation:** Python desktop automation libraries

## 📋 Requirements

- Python 3.10 or later, subject to project dependencies.
- An Anthropic API key.
- A working microphone for voice commands.
- An internet connection for Claude API access.

## 🚀 Installation

1. Clone or download the project.

2. Open the project folder in your terminal.

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure your Claude API key using an environment variable or the project's existing configuration system.

5. Run the application using its main Python entry-point file.

   ```bash
   python main.py
   ```

   Replace `main.py` with the actual entry-point filename if necessary.
